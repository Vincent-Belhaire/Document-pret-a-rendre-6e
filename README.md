# Document prêt à rendre · TICE 6e · Séance 9

Séance de **55 minutes** : corriger un document, l’enregistrer, vérifier l’aperçu et exporter en PDF avec LibreOffice Writer.

Charte graphique du **Bureau Mystère / Mission image**, sans commande de zoom. Défis interactifs, travail réel dans Writer et bilan détaillé imprimable en A4.

## Télécharger et démarrer

**[Télécharger la séance complète (ZIP)](https://github.com/Vincent-Belhaire/Document-pret-a-rendre-6e/raw/refs/heads/main/S09_Document_pret_a_rendre.zip)**

Extraire complètement l’archive, puis ouvrir **`index.html`** dans Firefox, Chrome ou Edge. Ne pas ouvrir le fichier directement à l’intérieur du ZIP.

Le ZIP de livraison contient uniquement les 13 fichiers utiles : site, images, documents et guide. Le menu GitHub **Code → Download ZIP** télécharge aussi les fichiers techniques du dépôt.

## Parcours

1. Repérer les défauts d’un document.
2. Corriger la présentation avec un défi avant/après.
3. Comparer ODT et PDF, choisir le nom et le dossier d’enregistrement.
4. Vérifier l’aperçu et préparer les réglages d’impression.
5. Exporter le PDF et contrôler la copie obtenue.
6. Réaliser la mission dans LibreOffice Writer.

Les commandes d’impression dans les défis sont simulées : elles ne déclenchent aucune impression réelle. Le bouton d’impression du bilan ouvre, lui, la boîte d’impression du navigateur.

## Ressources

- `ressources/document_a_corriger.odt` : brouillon élève de deux pages.
- `ressources/modele_corrige.pdf` : modèle de présentation d’une page.
- `enseignant/modele_corrige.odt` : correction modifiable.
- `enseignant/guide.html` : déroulé, réponses, adaptations et références.
- `assets/jardin_solaire.png` : image d’origine.
- `ressources/texte_depart.txt` : texte de secours.

## Bilan et données

20 critères à 50 points, soit **1 000 points**. Les aides et essais sont comptabilisés sans pénalité. Le score concerne le simulateur ; le fichier réalisé dans Writer n’est pas analysé automatiquement. L’autocontrôle de l’élève est à confirmer par le professeur.

Identité facultative. Sauvegarde locale désactivée par défaut ; aucun résultat n’est envoyé automatiquement par le site. Sur un poste partagé, conserver le bilan puis utiliser **« Nouvel élève · tout effacer »**.

Pour imprimer le bilan : **A4 portrait, échelle 100 %**, sans en-têtes et pieds de page ajoutés par le navigateur. Seul le bilan s’imprime depuis le parcours élève.

## GitHub Pages

Dans **Settings → Pages**, choisir **Deploy from a branch**, puis **main** et **/(root)**, et enregistrer. Conserver l’arborescence des fichiers. L’adresse sera indiquée par GitHub après publication.

## Vérifications

`CONTROLES.txt` décrit les tests effectués lors de la création. Le transfert contrôle en plus les empreintes SHA-256 des 13 fichiers pour conserver leur contenu à l’identique. `SHA256SUMS.txt` permet de vérifier la livraison.

Les fichiers `.build/` et le workflow servent uniquement au transfert et à l’assemblage : le site final n’en dépend pas et fonctionne hors ligne une fois téléchargé. La séance 8 n’est pas modifiée.
