TICE 6e — SÉANCE 09 — DOCUMENT PRÊT À RENDRE

DÉMARRER
Extraire complètement le ZIP, puis ouvrir index.html dans Firefox, Chrome ou Edge.
Ne pas ouvrir index.html directement à l'intérieur de l'archive.
Le site fonctionne hors ligne. Les liens d'aide officielle sont les seuls liens externes.

CHARTE
Style de S08 Mission image / Le Bureau Mystère. Aucune commande de zoom.

55 MINUTES
5 min briefing ; 7 min observer ; 8 min corriger ; 5 min enregistrer ;
6 min aperçu ; 4 min PDF ; 15 min Writer ; 5 min bilan.

RESSOURCES
ressources/document_a_corriger.odt : vrai brouillon à corriger (2 pages).
ressources/modele_corrige.pdf : modèle de présentation (1 page).
enseignant/modele_corrige.odt : correction modifiable pour le professeur.
assets/jardin_solaire.png : image d'origine, non déformée.
ressources/texte_depart.txt : texte de secours.
enseignant/guide.html : déroulé, corrections, évaluation et références.

BILAN
20 critères, 50 points chacun. Les aides et essais sont tracés sans pénalité.
Le score évalue le simulateur, pas le fichier de l'élève dans LibreOffice.
Le travail Writer fait l'objet d'un autocontrôle puis d'une validation professeur.
Imprimer le bilan : A4 portrait, échelle 100 %, désactiver les en-têtes et pieds
ajoutés par le navigateur. Seul le bilan s'imprime depuis le parcours élève.

CONFIDENTIALITÉ
Aucun compte et aucune transmission automatique. Identité facultative.
Sauvegarde locale désactivée par défaut. Sur un poste partagé : conserver le
bilan, puis cliquer sur « Nouvel élève · tout effacer ».

GITHUB PAGES
Déposer index.html, style.css, script.js et les dossiers à la racine d'un dépôt.
Conserver les chemins relatifs. Aucun serveur applicatif, aucune compilation.
Activer Pages sur la branche et le dossier racine choisis.

REMARQUES
Les interfaces sont des simulations pédagogiques simplifiées, pas Writer.
L'impression des défis est simulée : elle n'envoie rien à une imprimante.
Le navigateur ne lit ni ne vérifie le lecteur réseau P: ou les fichiers ODT.
L'export PDF ne remet pas automatiquement le devoir au professeur.
Les menus exacts peuvent varier légèrement selon LibreOffice.
